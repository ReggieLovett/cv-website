# Companion move references

The companion is a small fan-inspired sprite adaptation. Its 13 forms draw from 39 techniques. KCM and Sage Mode both include Rasenshuriken; KCM keeps four available moves, while combinations still contain only one to three. Names and attack shapes below informed the implementation; the animations simplify their scale and keep the character’s feet on the bottom edge. Sets draw from the character’s available arsenal, rather than claiming each technique is exclusive to one transformation.

## Naruto and Sasuke

| Form | Implemented techniques | References and adaptation |
| --- | --- | --- |
| Sage Mode | Frog Kumite; Sage Art: Giant Rasengan; Wind Style: Rasenshuriken | The [official anime retrospective](https://naruto-official.com/en/news/01_1321) describes all three in Naruto’s fight with Pain. Effects use natural-energy pressure, a large hand orb, and a four-bladed wind disc. |
| Chakra Cloak | Chakra Arm Barrage; Chakra Arm Rasengan; Wind Style: Rasenshuriken; Tailed Beast Bomb | Interpreted as the broader Kurama Link chakra cloak. [Official developer notes](https://naruto-official.com/en/news/01_1794?nolangsuggestion=1) describe Kurama Link claw attacks and Rasengan combos; [official Ninja Voltage notes](https://naruto-official.com/en/news/01_1472) describe its bomb. The requested sprite adaptation has an extended-hand barrage, a blue Rasengan carried by a golden chakra hand, and the same spinning four-bladed Rasenshuriken available in Sage Mode. “Chakra Arm Barrage” and “Chakra Arm Rasengan” are descriptive animation labels. |
| Baryon Mode | Baryon Rasengan; Baryon Tail Breaker; Baryon Breakthrough | The requested Rasengan is supported by [official Baryon Ninja Voltage notes](https://naruto-official.com/en/news/01_1340), which list “Baryon: Rasengan”. The tail and breakthrough labels come from [official Shinobi Striker DLC](https://en.bandainamcoent.eu/naruto/naruto-boruto-shinobi-striker/dlc). The sprite charges a blue hand orb while rushing, alongside its tail sweep and speed burst. These references are official game moves rather than claims about named manga attacks. |
| Six Paths Eyes | Chidori; Amaterasu; Susano’o Sword Slash | [Official Rinne Sharingan Sasuke notes](https://naruto-official.com/en/news/01_1674) describe Chidori and black flames. [Official Final Showdown notes](https://naruto-official.com/en/news/01_1472) describe Susano’o swinging its katana. The last display label describes that sword action; it is not a new named jutsu. |

## Original fantasy kits

These five forms are original companion effects, without a specific anime character attribution. Their descriptive moves avoid suggesting otherwise.

| Form | Techniques |
| --- | --- |
| Draw Sword | Quickdraw Slash; Cross Slash; Guard Break |
| Lightning Step | Lightning Thrust; Thunder Step; Chain Lightning |
| Phoenix Flame | Fireball; Flame Burst; Flame Wave |
| Frost Armor | Ice Spike; Frost Shield; Ice Shards |
| Shadow Clone | Shadow Clone; Shadow Strike; Shadow Feint |

All combinations contain one to three moves. Each named anime kit has different effect renderers for its available moves; the original kits also vary silhouette, timing, or release pattern when sharing a renderer. Movement is horizontal, including transformations, dashes, and teleport adaptations. Reduced motion applies forms without movement or combat effects.
